# Chart-layer glossary

| Layer | Meaning |
|---|---|
| Meaningful swings | Causally confirmed swing points. |
| HH/HL/LH/LL | Confirmed structural classification. |
| BOS / Origin BOS | Continuation or origin break evidence. |
| Dominant protection | Higher-order thesis invalidation. |
| Retracement | Active pullback region. |
| Fibonacci | Frozen parent impulse levels and location. |
| Counter structures | Opposing sequence owned by the pullback. |
| M1 monitoring | Parent-armed child observation window. |
| Entry triggers | Body-close entry level and marker. |
| Rejected candidates | Signals rejected with retained reasons. |
| Initial logical stop | Last important pre-BOS swing body edge. |
| Emergency stop | Separate broker-risk boundary. |
| Targets | TP1 and subsequent target state. |
| Trail candidates / proven trails | Proposed versus causally accepted protection. |
| Opposing BOS | Exit evidence against the active attempt. |
| Re-entry | One permitted fresh attempt under the same parent. |
| Bug flags | Diagnostic marker, never a trade action. |
| Trade outcome | Post-entry review only. |
| Shadow actions | Non-authoritative comparison policies. |

Presets choose combinations of these layers. Hiding a layer does not remove its
underlying event evidence.
