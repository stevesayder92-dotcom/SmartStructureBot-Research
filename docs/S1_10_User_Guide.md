# User guide

Run `run_simulator.bat`, wait for the browser to open, then select a curated
session and press **Load**. The first event shows only candles already closed at
the session start.

Use **Play**, previous/next, significant event, entry, exit, re-entry and flag
buttons. Speed changes playback delay, not strategy behavior. Use **Jump** for
an exact event. The two charts share event time; move across either chart for
candle OHLC and source index.

Choose Investor for the clean explanation, Normal for the full operating view,
or Debug for state hashes, raw event, state difference and the Steve review
form. Layer presets alter appearance only.

Shortcuts: Space play/pause; Left/Right event; Shift+Right significant event;
E entry; X exit; R re-entry; B flag; Home first event; End final event.

Use the export buttons or CLI packages for review. Mark entry, stop,
management and re-entry `ACCEPT`, `REJECT` or `UNCERTAIN`; notes are stored in a
separate ledger. This application is historical research, not order execution.
